# 使用与数据维护

## 日常日程

- 日历周视图按所选显示时区展示；周一开始。点击“新建日程”或使用 `Ctrl+N` 创建日程。
- `Ctrl+←` / `Ctrl+→` 切换当前周或月；`Ctrl+1` 切换周视图，`Ctrl+2` 切换月视图。
- 双击日历空白处可在对应日期创建事件。个人事件和已缓存的远端资料保存在本机 SQLite。

## Canvas

在设置页选择你的 Canvas 实例，输入个人访问令牌并保存。使用“测试连接”确认账户可读，再手动同步课程和作业。令牌只存于 Windows Credential Manager；断开后令牌删除，已缓存作业保留。

## SJTU 教务

选择本科或研究生并打开交大登录窗口，在窗口中自行完成交大统一身份认证。回到主窗口保存会话、填写课程学期首周周一及教学周数，再点击刷新课表。课程同步失败时应用会保留旧缓存。接口目前只有参考源码审计，首次使用后请对照教务页面核对课程、时间和地点，详见 [`integration-sjtu.md`](integration-sjtu.md)。

教务登录或刷新失败时会保留已有课表缓存，并显示错误。仍可新建和编辑个人日程。

## 备份与恢复

在设置页点击“导出数据库备份”，系统保存对话框默认打开 Downloads（下载）文件夹，可选择其他位置和文件名。保存成功后显示完整路径；取消不会生成文件。JSON 备份包含个人日程、Canvas 与教务缓存，不包含 Windows Credential Manager 的账号凭据。请将文件放在受信任的位置，因为它包含个人数据。

恢复时选择 SJTU Schedule 导出的 JSON，点击“验证并恢复备份”并确认。应用校验文件 SHA-256、SQLite 完整性及数据库版本，然后替换本机数据库；恢复前会在应用数据目录保留一份原数据库。恢复完成后请重新测试 Canvas，必要时重新登录教务。

## 问题处理

- “会话已保存”仅表示凭据在本机存在。若同步提示登录失效，重新打开登录窗口并保存会话。
- 网络错误、未知字段或空课表不会清空以前的缓存；检查网络、学期参数和学校访问要求后重试。
- 若恢复数据库失败，应用保留当前数据库并显示错误。不要删除应用数据目录中的 `calendar.sqlite3` 或 `calendar.pre-restore-*` 文件。
