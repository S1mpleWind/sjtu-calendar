## 每周 Todo

- 侧边栏新增「每周 Todo」入口，按显示时区以周一至周日组织任务。
- 本周置顶并默认展开，历史周默认折叠，点击日期可查看。
- 每周右侧「＋」可添加任务，跨周自动延续上周未完成任务及详情，几周未打开也会补齐记录。
- 单击任务标题展开详情，双击原位修改标题；Enter 或移开焦点保存标题，Esc 取消修改。
- 详情输入区随内容自动增高或收缩，并在重新展开、窗口宽度变化时重新适配。
- 详情自动保存，没有输入提示文案和保存／取消按钮。任务的标题、详情和完成状态分别更新，避免相互覆盖。
- 各周记录独立保存，修改历史周只影响该周。

## Windows 安装

下载下方 x64 安装包。支持选择安装位置；升级自动迁移到数据库 schema v10，保留既有数据。每周 Todo 随数据库备份和恢复保留。建议升级前导出备份。
