## 修复与新增

- 从 DDL 总览新建的日程默认勾选「纳入 DDL 总览」，避免保存后在总览中看不到。
- 日程保存或删除失败时，在编辑弹窗内显示具体原因并保留输入；保存状态独立于后台刷新，防止重复提交。
- 修改开始时间超过结束时间时会顺延结束时间；保存前检查时间顺序并显示提示。
- 长期清单支持备注：新增时可填写，已有和归档事项均可编辑，最多 4000 字，归档和恢复时保留。

## 安装

下载下方 Windows x64 安装包，支持选择安装位置。升级会自动迁移至数据库 schema v9，保留现有数据，旧长期事项的备注默认为空。建议升级前导出备份。
