## 更新

- 打开 DDL 总览时默认显示当前月份，不再沿用日历之前选中的月份。
- 提供明确的「上月 / 本月 / 下月」按钮，支持切换月份和快速回到当前月份。
- DDL 总览标题显示所选年月，随月份切换更新。
- 导出数据库备份时弹出系统保存对话框，可选择路径和文件名，默认打开 Downloads（下载）文件夹；保存后显示实际路径，取消则不导出。
- 保留 v1.1.1 的 Canvas 已提交作业自动勾选修复。

## 安装与验证

下载下方 Windows x64 安装包。支持选择安装位置，升级保留已有日程和缓存。
