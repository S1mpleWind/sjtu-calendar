## 新增长期清单

- DDL 总览右侧「每日清单」下方新增「长期清单」，可手动添加不限定日期的事项。
- 勾选完成后自动归档，点击「归档」可查看已完成事项和归档日期。
- 在归档中取消勾选，可将事项恢复到待办清单。
- 清单保存在本地 SQLite 数据库中，切换月份、重启以及备份恢复时都会保留；不影响每日 DDL 圆圈颜色。

## Windows 安装

下载下方 x64 安装包，支持选择安装位置。升级自动迁移到数据库 schema v8，并保留已有日程和缓存。建议升级前从设置导出备份。
